### 🚀 Featured Projects

#### ✈️ Quadrotor Dynamics and Control Simulation
> Simulated quadrotor motion using **MATLAB & Simulink**  
> Implemented **PID control** for stabilizing position and orientation  
> Analyzed system behavior using sine & square wave inputs  
> 📊 Gained hands-on experience in tuning controllers for nonlinear systems  

#### 🌱 Soil Health Monitoring System
> IoT-based **Soil Health Monitoring System** for farmers  
> Measures parameters like pH, N, P, K, and moisture using sensors  
> Real-time data with **Firebase** + ML-based crop recommendation  
> 🛰️ A step toward smart and sustainable agriculture  

#### 🧺 SmartCart
> Automated cart management system for retail stores  
> Scans products, updates total in real-time, and generates QR for payment  
> 🛒 Focused on automation, embedded logic, and real-time communication  

#### 🌡️ Cabin Environment Control
> Smart cabin system that predicts temperature and humidity  
> Used sensor data + ML model to create a comfortable environment  
> ☁️ Data handled through **Firebase** in real-time  

#### 🧭 Edge AI Research
> *Efficient Deployment of TinyYOLOv8 and MobileViT on Jetson Orin Nano*  
> Exploring **quantization, pruning, and TensorRT** for real-time inference  
> ⚡ Comparing accuracy vs latency trade-offs for embedded AI systems
